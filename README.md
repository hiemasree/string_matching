# Comparative Analysis of Naive, Rabin-Karp, and KMP Algorithms

## Objective
Compare three famous string matching algorithms based on execution time and number of pattern matches.

## Algorithms
- Naive String Matching
- Rabin-Karp Algorithm
- Knuth-Morris-Pratt (KMP)

## Language
py

## Time Complexity

| Algorithm | Best | Average | Worst |
|-----------|------|---------|-------|
| Naive | O(n) | O(nm) | O(nm) |
| Rabin-Karp | O(n+m) | O(n+m) | O(nm) |
| KMP | O(n+m) | O(n+m) | O(n+m) |

## Output
Displays:
- Number of pattern matches
- Execution time of each algorithm
